GitHub 연동 설정

이 시트는 GitHub 저장소에 데이터를 저장해서 여러 명이 동기화합니다. 아래 정보를 두 사람 모두 동일하게 입력해야 같은 데이터를 봅니다.

GitHub → 우측 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access는 이 저장소만 선택, Permissions에서 Contents: Read and write 로 설정하세요.
토큰은 이 브라우저에만 저장되며(localStorage), 저장소에 커밋되지 않습니다. 단, 이 페이지 소스를 보는 사람은 설정값을 볼 수 있으니 신뢰하는 사람과만 공유하세요.
